# Stabilizing the ambitious run's routed experts (2026-10-28 – 10-30)

## Decision

**Use `pab`, the post-activation bound inside the SwiGLU of every MLP** (routed experts, shared experts, dense MLPs):

```
h = silu(gate) * up            # SwiGLU output, per token and expert, width F
h = h / max(rms(h), 1)         # pab: identity below rms 1, scaled to rms 1 above
out = fc2(p * h)               # p: the router probability
```

Settings: `moe_expert_post_act_norm: true`, `mlp_post_act_norm: true`, `post_act_norm_floor: 1.0`. No learnable gain, no lr or
warm-up change.

| evidence | result |
|---|---|
| reproducer of the ambitious run | largest routed-expert output flat at ~0.07 up to step 900; unchanged model: 6.7 and rising |
| s3 (vs current LDM + Muown) | **−0.005** final; −0.005 to −0.008 in every 200-step window from step 400 to 4000 |
| s2 | **+0.000** final; within ±0.002 throughout |
| s1 | −0.003 final |
| cost at 64 nodes | about −0.1 % speed, +0.4 GB memory |

Every alternative was tested on the same layouts and batches:
- optimizer-side decays and lr changes;
- an activation clamp;
- full post-activation normalization;
- peri-LN;
- stable-rank floors, spectral-norm caps, combinations with `pab`, orthogonal expert directions.

Each one lost, faded or was erratic. Following the user's call (2026-10-30: "don't over-optimize once something stays on par and
serves stability"), the search is closed.

**Not achieved:** no variant reproduced nGPT's steadier, more linear late loss decay. The closest constraint, orthogonal expert
directions, costs +0.020 at s3.

## 1. The problem

In the ambitious main run (LDM residual, classical Muown without weight decay, constant lr 8.5e-4, 216 routed experts top-5,
MoonEP, 64 nodes):
- the routed-expert output RMS of layers 55–73 rose from ~0.05 to 1.5–7 between steps 400 and 870;
- the routed share of the MoE output reached 0.99;
- the grad norm hit 12 at step 869.

None of the s1–s3 screens ever showed it.

## 2. Diagnosis: what it is and what it isn't

**What it is: single-expert spectral collapse.** Weight spectra of the main run at step 850 and of the reproducer at step 900
(`scripts/korbi/campaign/expert_spectra.py`, Gram eigenvalues plus power iteration, one checkpoint load) show it.
- In each affected layer, one routed expert out of 216 collapses:
  - its stable rank |W|_F²/σmax² drops from ~200–300 to single digits;
  - its fc1 and fc2 co-align: alignment of fc2's input directions with fc1-up's output directions 0.95, against 0.75 for the others.
- Its Frobenius and row norms stay flat.

| case | runaway expert | end-to-end gain (median) | fc1 σmax (typical) | fc2 σmax (typical) | fc2 top-5 share (typical) |
|---|---|---:|---:|---:|---:|
| reproducer `base`, step 900, layer 73 | expert 39 | 10.0 (0.30) | 5.5 (1.56) | 1.92 (0.26) | 0.25 (0.02) |
| main run, step 850, layer 65 | expert 49 | 9.1 (0.40) | 6.2 (1.8) | 1.53 (0.34) | – |
| main run, step 850, layers 69 / 71 | experts 7 / 201 | 3.6 / 2.8 | | | |

`pab` at step 900: no runaway expert, max gain 0.54.

**What it is not:**

| suspect | finding (tool) |
|---|---|
| Muown row magnitudes g | moved ≤ 5 % (`muown_g_stats.py`): the growth is not a norm drift |
| router | load entropy ~0.998, max_vio < 1, min dispatched-load entropy 0.985 in all runs |
| pre-MLP norm gains | +10–14 % in the deep band (`norm_scale_stats.py`), the same in stabilized runs |
| LDM | read gain +30–55 % the same way in stabilized runs; forget λ ≈ 0.986–0.99; address-net norms ≈ 1 (LDM health check of 2026-10-29) |
| tokens per step | the reproducer, at 1/8 of the tokens per step, blows up at the same steps |

**It is step-driven.** Muown's direction norm ‖v‖ grows like lr·√t, so its late rotation per step is ~1/√t, independent of the
lr. Muown has no weight decay, and nothing pulls a direction back once it starts to dominate.

**Why norm caps miss it:** the collapse happens at flat norms, so anything that caps a norm does not see it. The two things that do
see it are:
- a bound on the activation (what fc2 receives);
- a bound on the spectrum.

## 4. Everything tried

Gaps are against the reference `ldm`; negative is better. Steps are training steps of 4000. "×" means stopped early (predictable).

### 4.1 Optimizer side

**Rationale:** Muown has no weight decay, so a decay should pull back the growth. For v (the unnormalized directions), decoupled
decay holds ‖v‖ at an equilibrium. That makes the rotation rate settle at ~√(2·lr·λ) instead of annealing like 1/√t. For g (row
magnitudes), decay caps |g| at about 1/λ.

| arm | s1 | s2 | s3 | verdict |
|---|---:|---:|---:|---|
| v decay 0.1 / 0.01 / 0.001 | +0.012 / +0.005 / +0.000 (× ~1340) | | | costs loss in proportion to its strength |
| g decay 1 / 0.3 | +0.083 (× 1710) / +0.035 | | | bad, and g isn't what grows |
| 200-step warm-up (`wu`) | −0.003 | | | small; later excluded (no warm-up) |
| half lr (`lr2`) | −0.008 (`pan_lr2`, `mcl_lr2e3`) | −0.001 (−0.008 at 3200) | −0.002 (−0.009 at 3200) | helps, but excluded: no lr changes |

### 4.2 Activation side, inside the SwiGLU

**Rationale:** the runaway multiplies fc1's growth by fc2's alignment. Bounding what fc2 receives cuts that loop, whatever the
weights do. Implemented as one fused SwiGLU + bound + router-weight kernel.

| arm | what | s1 | s2 | s3 | reproducer at steps 800–900 vs `base` | verdict |
|---|---|---:|---:|---:|---:|---|
| clamp 5 | activation clamp 5 instead of 10 | +0.006 (× 570) | | | | worse |
| `pa` | full rms norm h/rms(h), routed experts only | −0.004 | | +0.005 | | mixed |
| `pan` | full rms norm, routed + shared | −0.001 | +0.001 | +0.008 | +0.018, stable | costs at s3: it also rescales the small activations |
| `pan_wu` | `pan` + warm-up | −0.009 | | | | warm-up excluded |
| **`pab`** | **bound h/max(rms(h), 1), routed + shared + dense** | **−0.003** | **+0.000** | **−0.005** | **+0.009 / +0.006 (twins)**, stable | **chosen** |
| `pab_lr2` | `pab` at half lr | | −0.000 | −0.003 | | lr excluded |

**How often `pab` binds:**
- s3: mean rms(h) 0.45; 3.1 % of rows at or above 1.
- Ambitious model, without `pab` (the cancelled κ = 3 reproducer run, new data): 13–29 % of rows above 1, rising over the run.

So in the ambitious model the bound does real work on a quarter of the rows. That likely explains its reproducer cost. The
reproducer cost is also measured against a `base` that has not yet paid for its runaway expert.

### 4.3 Residual stream: peri-LN

**Rationale:** normalizing every sublayer's output (`post_sublayer_norm`, learnable gain) bounds each layer's write to the residual
stream.

| | s1 | s2 | s3 | reproducer |
|---|---:|---:|---:|---|
| peri-LN | −0.001 | +0.004 | +0.001 in the last 200 steps (−0.011 in the last 100) | −0.065 at 300–400, fading to −0.002 at 800–900; expert output 0.046 → 0.090 (rising) |

- **Erratic:** at s3 its 200-step gaps swing between −0.025 and +0.039.
- **Spikier:** about 2× the grad-norm spikes of every other arm (13–16 vs 3–10 per 1000 logged points), and a median grad norm
  30–50 % higher.
- **Fading:** its early lead in the reproducer is a fast start that fades.

### 4.4 Weight spectrum (Muown, routed experts only)

**Rationale:** the collapse is spectral, so bound the spectrum directly. All three bounds run after each optimizer step:

| bound | what it does |
|---|---|
| stable-rank floor (`muown_expert_stable_rank_floor`) | exact rank-1 deflation of the top singular direction to the value that gives stable rank r_min |
| spectral cap (`muown_expert_spectral_cap`) | σmax ≤ κ·σ_init; the matrix is scaled by min(1, cap/σmax); σ_init = rms·(√m+√n) per shape, from the init weights |
| orthogonal directions (`muown_expert_orthogonal`) | Muon-like weight balancing: W = diag(\|W_i\|)·Q/\|Q_i\|, Q the polar factor of the row-normalized weight |

All three:
- use power iteration or a convergent cubic Newton–Schulz iteration: batched matmuls, below the cost of Muon's own Newton–Schulz
  step;
- cost ~1 % step time on the Megatron-FSDP path, which floors or caps at the matrix owners through the row exchange.

| arm | s2 | s3 | notes |
|---|---:|---:|---|
| floor 25 / 50 / 100 | 50: −0.004 (× 2580) | −0.001 / +0.001 / −0.000 | neutral; the reproducer run was cancelled at step 261 |
| cap κ = 3 | −0.001 | −0.002 | led `pab` by 0.014 at steps 200–400, then 0.003 behind it from step 1600; binds < 1 % of fc2 after step 1000 |
| cap κ = 5 | | +0.003 | almost never binds |
| cap κ = 2 | +0.001 | +0.005 (× 1680) | binds 6–7 % of fc2; costs |
| `pab` + cap κ = 3 | −0.004 | +0.001 (× 1680) | inconsistent across scales |
| orthogonal directions | | +0.020 | drift from orthogonal 0.003 per step, 2 iterations; the gap shrinks only slightly in the decay (+0.023 → +0.020) |

**Reading:**
- The spectral bounds mostly sit idle in healthy training. At s2/s3 they show only their side effects, and those are ~0.
- κ = 3's early gain is a constraint on the young expert matrices, early in training, and it washes out.
- Whether a cap alone stops the runaway is untested: the κ = 3 reproducer run was invalid (§3).

### 4.5 Router

Quantile balancing instead of the expert bias + aux loss was handed to another agent (`screen5qb_*`, `ambrepro_qb`). The router
was healthy throughout, so it isn't a stabilization candidate.

## 5. Grad-norm spikes

**What was counted:** single-step spikes above 3× the local median of the surrounding 100 steps, after step 200.

**Result:**
- Every arm has them at 3–10 per 1000 logged points, at 3–14× the local median, without loss spikes. This includes the reference
  and `pab` (`pab_r`'s 31× at step 517 is one of them).
- Peri-LN has about 2× as many.

**They are not the signal of the instability:** in `base` the runaway is a steady rise of the expert output (0.13 → 6.7) at a
normal spike rate. Monitor `moe/routed_expert_output_rms_max`, not the grad norm.

## 9. Lessons for the next campaign

- **Noise:** measure it with an identical twin before reading small gaps: 0.003 in the reproducer at step 800, ~0.002–0.003 at
  s3.
- **Pin the data and the balancing in every comparison config.** A config that inherits from production changes silently when
  production does.
- **Early windows mislead:** κ = 3 at s3 led by 0.014 early and ended behind. Peri-LN led by 0.065 in the reproducer and was
  fading. Judge on the full run, including the decay.
- **Pool retries** auto-restart failed jobs from their old snapshot: cancel the retry before re-enqueueing. Separate single-arm
  launches of one suite overwrite each other's `task_0.sh`: launch all arms together.
- **A pool host releases itself** when nothing it can run is queued: the cns144 host was lost on 2026-10-30. Keep work queued or
  hand it back deliberately.
- **Spectral bounds on Megatron-FSDP shards** must see the full matrix, not the local rows: the first floor crashed on empty
  shards and would have used the wrong stable rank.
