## Obtain and verify

Use a new checkout or preserve all local work before updating an existing one. Initialize the Megatron submodule explicitly: switching the outer Git branch alone does not select the new Megatron source. This needs Git and Python 3.10+ from your activated project environment; source verification does not import PyTorch or use GPUs.

```bash
git clone --branch oellm-32b-b1-reborn-20260925 \
  https://github.com/OpenEuroLLM/oellm-autoexp.git oellm-autoexp-b1
cd oellm-autoexp-b1
git submodule update --init -- submodules/Megatron-LM
python tools/megatron_release.py verify-checkout \
  --name oellm-32b-b1-reborn-20260925
```

The verification must report Megatron commit `799ff4e6e1c3f6762283c97cd76ab4eb68073720` and the tree above. Only Megatron is required; the unrelated Titan submodule is not initialized by these commands. Repository access is required if the repositories are private. For standalone Megatron use, clone `https://github.com/OpenEuroLLM/NVIDIA-Megatron-LM.git` at the same release tag.

## What this version contains

The deferred-gradient fix prevents a head bucket from scaling, copying or communicating gradients while deferred GEMM contributions are still pending. After the drain, the normal finish path dispatches it once. It handles empty drains and the one-deferred-microbatch case, without adding device-wide synchronization. The patch changes `megatron/core/tensor_parallel/layers.py`, `megatron/core/distributed/param_and_grad_buffer.py`, `megatron/core/utils.py` and the distributed regression tests. The exact historical binary patch hash is `54c7a445941135268266149218a21c51ce518a59465eda1f92d7ba38ee2c70c5`.

Its ancestry also contains the native CE/z-loss FP32 backward correction, independent final-norm decay, embedding/QK/residual-norm decay controls, diagnostics and checkpoint parameter-group support already used by B1. Expensive gradient-oracle launchers are absent from this clean source. The local archived debug commit `125bf13f5cde74bedf72e13e7f4534ee53fd16f0` remains separately preserved for investigations; this release does not select it.

## Using it in a 32B run

Use the submodule as both the launch source (`submodules/Megatron-LM/pretrain_gpt.py`) and the Megatron import location inside the training container. Remove any old externally selected Megatron checkout from that run's launch/PYTHONPATH configuration. Inspect the rendered autoexp command before submission. The B1 source recipe was validated with the following settings; changing the source version does not automatically change an existing experiment's flags:

| Setting | B1 production value |
|---|---|
| Deferred head wgrad / gradient overlap | both enabled |
| Parameter-gather / TP communication overlap | both enabled |
| FP8 | hybrid, delayed scaling; history 1024, max amax |
| Cross entropy | native fused CE with the FP32 correction |
| Output z-loss coefficient | `1e-5` |
| Global LR / Adam epsilon | `3e-4` / `1e-8` |
| Weight decay | `0.1` |
| Embedding / residual pre-norm WD multipliers | `0` / `0` |
| QK-norm / final-norm WD multipliers | `1` / `1` |
| Global / micro batch, sequence length | `4096` / `2`, `4096` |
| Tested full topology | TP4, PP4, DP128: 512 GH200 nodes, 2048 GPUs |

The legacy QK-only WD switch is false; the independent multipliers select the intended scope. B1 keeps ordinary, not zero-centered, norms. The source pin alone does not reproduce a full training experiment: preserve your resolved config, dataset/data position, full optimizer/RNG checkpoint, image, environment and scheduler policy. In particular, changing optimizer parameter-group hyperparameters when importing another recipe requires an explicit audited post-load procedure; the B1 conservative/old-production 60k continuation wrappers implement that outside Megatron. This source release does not silently reset Adam or install those campaign-specific wrappers.

The tested image is `MegatronTraining-JUPITER-te218-fa3_aarch64_202608280932.sif` with the checksum above. Git does not contain that image, compiled dataset helpers, caches, datasets or weights. Provision a compatible platform environment using the project's container setup; generated native helpers must be built for that environment. No assertion of identical startup performance on a fresh checkout or support for every untested topology is implied.

## Validation evidence

The original defer-on/overlap-on implementation failed small known-bad controls before trajectory divergence. The patched version passed small, 16-node and 512-node checks comparing gradients within the same execution, avoiding whole-run reproducibility as a confounder. Final 512-node job `1883750` passed both full 1,342,177,280-coordinate head captures, worst relative L2 `2.63e-7`, zero FP64-bound violations, and all 16 contributions before one dispatch. That test used production FP8, fused CE, overlaps and ordinary nondeterministic controls. These are observed head-gradient and lifecycle checks, not an independent proof of every transformer-body derivative.

Clean 190k sanity job `1884714` completed 100 updates without skipped/NaN iterations. The source was promoted for the long B1 run from 192k in job `1885312`, and the same commit is used by the later matched old-production/conservative 60k continuations. Training histories still need their own stability/evaluation assessment; fixing gradient handling does not guarantee a particular loss trajectory.

Full reproducible test records and the exact patch are in `SLAMPAI/oellm-workflows`, `oellm_32B_loss-increase_debug/milestones/deferred_wgrad_20260918/`, with the original oracle implementation published at workspace commit `038266a6150111cdd1cfb9aad60c4e859bbeddc2`. Guides: `Claude/DEFERRED_WGRAD_ORACLE.md`, `Claude/DEFERRED_WGRAD_MILESTONE.md`, `Claude/B1_DEFER_PATCH_SANITY.md` and `Claude/B1_DEFER_PATCH_PRODUCTION.md`. The archived validated source inventory contains 2,971 tracked files/modes. The release publisher additionally verifies source preservation, exact Git trees, ordered remote publication and fresh network submodule restoration. Packaging tests do not replay GPU training.
